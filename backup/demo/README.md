# Mantle demo

Frontend-only HTML/CSS/JS demo of the Mantle well-to-surface digital twin
(Baghewala-S synthetic data — every number is SIM / EST / ASSUM / PUB).

## Run

```bash
cd demo
python3 -m http.server 8091
# open http://localhost:8091
```

## Routes

`#/well` living 3D twin · `#/well/bp` blueprint · `#/field` `#/arena`
`#/ledger` `#/impact` `#/proof` · `#/play` judge challenge · `#/m` mobile card

## Keys

`1–6` screens · `B` twin⇄blueprint · `C` condition deck · `⌘K` ask ·
`Space` play · `←→` step · `L` lens · `X` x-ray · `F` fork · `S` story mode ·
`.` provenance tint · `?` help
